# Shell Scripting Exercises

A set of Bash scripts from a systems/Linux course, covering regex-based validation, text processing with `sed`, argument handling, and basic arithmetic.

| Script | What it does |
|---|---|
| [`ip_phone_validator.sh`](ip_phone_validator.sh) | Reads a file line by line and validates each line as both an IPv4 address and an Iranian mobile phone number |
| [`regex_toolkit.sh`](regex_toolkit.sh) | Menu-driven tool for searching, replacing, and counting regex matches in a file using `sed` |
| [`arg_handler.sh`](arg_handler.sh) | Behavior changes based on argument count: print a file's lines, divide two numbers, or save three arguments to a file |
| [`calculator.sh`](calculator.sh) | Basic command-line calculator (`+`, `-`, `*`, `/`) with divide-by-zero handling |

## Usage

```bash
chmod +x script_name.sh
./script_name.sh [args]
```
