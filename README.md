# Linux Kernel Compilation & Shell Scripting

A small portfolio of hands-on Linux work: building a custom kernel from source on Ubuntu Server, and a set of Bash scripting exercises.

## Contents

- **[`kernel-build/`](kernel-build/README.md)** — step-by-step walkthrough of downloading, configuring, compiling, and booting a custom Linux 6.1 kernel, including the real errors encountered along the way and how each one was fixed.
- **[`shell-scripting/`](shell-scripting/README.md)** — Bash scripts covering regex-based validation, `sed`-based text processing, and argument handling.

## Environment

- Ubuntu Server (VM)
- Linux kernel 6.1.144, built from source ([kernel.org](https://kernel.org))
